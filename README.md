💊 Sistema de Pedidos para Droguería

Proyecto desarrollado en Python para el control de productos, ventas y pedidos de una droguería.

Funciones principales

📦 Registro de productos

Permite registrar medicamentos y productos con su código, descripción, unidad de venta, costo, porcentaje de utilidad y existencia disponible.

💰 Venta de productos

Permite realizar ventas a clientes, registrar pedidos, seleccionar la forma de pago y actualizar automáticamente el inventario.

🧾 Facturación de pedidos

Permite buscar un pedido por su número y marcarlo como facturado.

📋 Ver productos 

Muestra todos los productos registrados junto con su precio de venta y existencia disponible.

📊 Estado de cuenta

Genera un resumen de las ventas realizadas, mostrando pedidos, clientes, productos vendidos y total de ingresos.

Herramientas utilizadas: 

- Python
- Visual Studio Code

Objetivo:

Este proyecto fue desarollado con el fin de crear un sistema que ayudara a los empleados de una droguería a organizar y controlar sus pedidos y ventas de forma más eficiente.
